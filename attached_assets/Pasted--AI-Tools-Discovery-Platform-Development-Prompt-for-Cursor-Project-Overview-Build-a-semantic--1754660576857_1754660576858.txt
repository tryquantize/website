# AI Tools Discovery Platform - Development Prompt for Cursor

## Project Overview
Build a semantic AI tools discovery platform that connects businesses with relevant AI solutions through natural language search. The platform features a ChatGPT-like interface for clients and a comprehensive dashboard for AI tool creators.

## Tech Stack Requirements

### Frontend
- **Framework**: Next.js 14+ with App Router
- **Styling**: Tailwind CSS with shadcn/ui components
- **State Management**: Zustand or Redux Toolkit
- **UI Libraries**: 
  - Framer Motion for animations
  - React Hook Form for forms
  - Recharts for analytics
  - Lucide React for icons

### Backend
- **Runtime**: Node.js with TypeScript
- **Framework**: Express.js or Fastify
- **Database**: PostgreSQL with Prisma ORM
- **Vector Database**: Pinecone or Weaviate for semantic search
- **Authentication**: NextAuth.js or Clerk
- **File Storage**: AWS S3 or Cloudinary
- **Email**: Resend or SendGrid

### AI/ML Services
- **LLM Provider**: OpenAI GPT-4 or Anthropic Claude
- **Embeddings**: OpenAI text-embedding-3-large
- **Vector Search**: Similarity search with cosine distance

## Database Schema

```sql
-- Users table
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email VARCHAR UNIQUE NOT NULL,
  name VARCHAR,
  role ENUM('client', 'startup', 'admin'),
  created_at TIMESTAMP DEFAULT NOW()
);

-- AI Tools table
CREATE TABLE ai_tools (
  id UUID PRIMARY KEY,
  name VARCHAR NOT NULL,
  description TEXT,
  one_liner VARCHAR(200),
  website_url VARCHAR,
  pricing_model ENUM('free', 'freemium', 'paid', 'enterprise'),
  pricing_details JSONB,
  features TEXT[],
  industries TEXT[],
  integrations TEXT[],
  tech_stack TEXT[],
  demo_video_url VARCHAR,
  logo_url VARCHAR,
  startup_id UUID REFERENCES users(id),
  status ENUM('pending', 'approved', 'rejected'),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Tool embeddings for semantic search
CREATE TABLE tool_embeddings (
  id UUID PRIMARY KEY,
  tool_id UUID REFERENCES ai_tools(id),
  embedding VECTOR(1536), -- OpenAI embedding dimension
  metadata JSONB
);

-- User searches and interactions
CREATE TABLE search_queries (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  query TEXT NOT NULL,
  results_shown INTEGER,
  clicked_tools UUID[],
  created_at TIMESTAMP DEFAULT NOW()
);

-- Analytics for startups
CREATE TABLE tool_analytics (
  id UUID PRIMARY KEY,
  tool_id UUID REFERENCES ai_tools(id),
  date DATE,
  impressions INTEGER DEFAULT 0,
  clicks INTEGER DEFAULT 0,
  contact_requests INTEGER DEFAULT 0
);
```

## UI/UX Implementation Guidelines

### Design System
- Use a consistent color palette with primary, secondary, and accent colors
- Implement dark/light mode toggle
- Ensure accessibility with proper contrast ratios and keyboard navigation
- Use consistent spacing (4px, 8px, 16px, 24px, 32px scale)

### Responsive Design
- Mobile-first approach with breakpoints at 640px, 768px, 1024px, 1280px
- Collapsible sidebar navigation for mobile
- Touch-friendly button sizes (minimum 44px)

### Performance Optimizations
- Implement virtual scrolling for large result sets
- Use React.memo and useMemo for expensive computations
- Lazy load images and implement skeleton loading states
- Cache search results and embeddings

### Animation Guidelines
- Use Framer Motion for smooth page transitions
- Implement micro-interactions for button hovers and clicks
- Add loading animations for search and data fetching
- Use spring animations for natural feel
